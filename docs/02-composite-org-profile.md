# 2. Composite organization profile (FICTIONAL)

> **Composite Regional Health System (CRHS) is fictional.** It blends common traits of U.S. regional nonprofit health systems. It does not describe any real employer.

| Trait | CRHS (fictional) | Why it's realistic |
|---|---|---|
| Type | 501(c)(3) nonprofit, files a group Form 990 | Common for multi-hospital systems |
| Hospitals | 1 regional referral hospital (about 400–500 beds, trauma center), 1 community hospital, 3 small rural / Critical Access Hospitals | Typical rural-plus-hub footprint |
| Other sites | About 60 clinics and urgent care centers, home health, transport | Common outpatient spread |
| Workforce | About 5,000–6,000 people | Typical for this size |
| Revenue | About $1 billion a year | Typical for this size |
| EHR | One major commercial EHR with a patient portal used by tens of thousands of patients | Most U.S. hospitals use one of a few vendors |
| IT stack signals | ITSM ticketing, SaaS HR/payroll, hybrid cloud and on-prem data, HL7/FHIR interfaces | Seen across public healthcare job posts |
| Money pressure | Thin margins and Medicaid changes | Sector-wide in 2025–2026 |
| Dependencies | Claims clearinghouse, pharmacy-support vendors, staffing companies, cloud/SaaS | Change Healthcare showed how deep these go |

## What we can't know from outside (and shouldn't try to)
Specific security tools, internal network design, actual patch levels and control maturity. These are **questions for the interview**, not targets for research.
