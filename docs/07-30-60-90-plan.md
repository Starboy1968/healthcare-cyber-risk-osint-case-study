# 7. 30/60/90 day plan and recommended actions

## Days 1–30: Listen and map
- Meet every stakeholder role. Ask what worries them and what security makes harder.
- Learn the incident plan and escalation path.
- Review the scanner, ticketing, risk register, current SLAs and exceptions.
- Inventory HIPAA evidence and note the gaps.
- **Output:** a current-state one-pager.

## Days 31–60: Stand up the rhythm
- Launch the weekly KEV-first review with IT.
- Draft the SLA standard and exceptions process, and get feedback.
- Start the critical vendor list and tiering with Procurement.
- Set the metric baselines.
- **Output:** approved standard and the first dashboard.

## Days 61–90: Prove value
- Clear or formally except all past-due Tier 1 items.
- Run one restore test or tabletop that includes a small rural hospital.
- Map the evidence library to HIPAA and HICP and review it with Compliance and Internal Audit.
- Propose the next-quarter roadmap.
- **Output:** a 90-day readout.
