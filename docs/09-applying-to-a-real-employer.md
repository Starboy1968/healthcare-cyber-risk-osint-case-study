# 9. How I'd apply this to a real employer

1. **Redo the OSINT with the same rules.** Use the employer's public site, Form 990, the HHS OCR portal (archive and current), state AG notices where public, news, and public job posts. Keep it passive and organization-level, with no individuals named.
2. **Check the name.** Confirm every finding by city, state and facility. Similar names are common in healthcare.
3. **Swap sector evidence for org evidence where it exists.** For example, if public records show incidents came through vendors, move third-party risk to the top.
4. **Keep the internal-tool questions for the interview.** Ask which scanner, GRC tool and SLAs they use. Don't guess, and never probe.
5. **Keep it private.** Employer-specific findings go in a private interview brief, not a public repo.
6. **Show up with a 90-day plan, not a verdict.** Outside-in research shows what to ask, not how mature they are.
